Unofficial · Open Source · Local First

Your Fitbit signal should be readable by your agent, not trapped in screenshots.

Fitbit MCP connects AI agents to your authorized Fitbit Web API data: activity, sleep, heart rate, HRV, SpO2, breathing rate, weight, food and water logs. Tokens stay local. Raw data is opt-in. Medical diagnosis is out of scope.

Boundary

Useful health context without pretending to be a doctor.

This bridge exposes processed Fitbit Web API data. It does not expose raw accelerometer telemetry, private Google endpoints, or medical diagnosis.
